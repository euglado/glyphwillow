# Security / Güvenlik

English: Never include real tokens, private text or `.env` in issues. Reset leaked tokens in Developer Portal immediately, stop the bot and reconfigure. Use GitHub private vulnerability reporting if available; otherwise open a minimal issue asking for a private contact, with no exploit details or secrets. Do not attack deployed bots. This Unicode workshop does not certify text as safe, find all invisibles/lookalikes or authorize moderation. Keep Node24/dependencies updated, run one process, review access, protect `.env`/backups and rerun all checks after updates.

Türkçe: Gerçek token, özel metin veya `.env` dosyasını issue'ya koymayın. Sızan tokenı Portal'da hemen sıfırlayın, botu durdurun ve yeniden yapılandırın. Varsa GitHub özel güvenlik bildirimi kullanın; yoksa açıklık ayrıntısı veya sır paylaşmadan özel iletişim isteyen kısa bir issue açın. Çalışan botlara saldırmayın. Bu Unicode atölyesi metnin güvenli olduğunu onaylamaz, tüm görünmez/benzer karakterleri bulmaz ve moderasyon kararı vermez. Node24/bağımlılıkları güncel tutun, tek süreç çalıştırın, erişimi ve `.env`/yedekleri koruyun, güncellemelerden sonra kontrolleri tekrar çalıştırın.
